# Nitos_OS

**Nitos_OS (Νι.Τοσ)** is an Ubuntu-based Linux operating system.

Pronounced: Ni.Tos

## Vision

Nitos_OS aims to provide a modern, minimal, and efficient
desktop experience for desktop computers and laptops.

## Features

- Ubuntu-based Linux distribution
- Modern, minimal desktop design
- Custom Nitos_OS branding
- KDE Plasma desktop initially
- Gradual development of an original desktop environment
- Support for a range of PC hardware

## Project Status

Early development.

The initial goal is to create a customized, bootable Linux ISO.
